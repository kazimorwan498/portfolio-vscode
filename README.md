# Kazi Morwan - Personal Portfolio

একটি আধুনিক, প্রতিক্রিয়াশীল ব্যক্তিগত পোর্টফোলিও ওয়েবসাইট যা React, TailwindCSS এবং Framer Motion দিয়ে তৈরি।

## ✨ বৈশিষ্ট্য

### 🎨 ডিজাইন

- **মিনিমালিস্ট ডিজাইন**: পরিচ্ছন্ন এবং মনোযোগ আকর্ষণকারী লেআউট
- **ডার্ক/লাইট মোড**: সম্পূর্ণ থিম টগল সাপোর্ট (লোকাল স্টোরেজ সহ)
- **মসৃণ অ্যানিমেশন**: Framer Motion দিয়ে প্রফেশনাল অ্যানিমেশন
- **মোবাইল-ফার্স্ট রেসপন্সিভ**: সব ডিভাইসে নিখুঁত প্রদর্শন

### 📱 বিভাগ

- ✅ Hero Section - আকর্ষণীয় ইন্ট্রোডাকশন এবং CTA বাটন
- ✅ About Me - ব্যক্তিগত পরিচিতি এবং পেশাগত তথ্য
- ✅ Skills - আইকন সহ প্রযুক্তি স্ট্যাক (৩টি ক্যাটাগরি)
- ✅ Projects - ৪টি প্রিমিয়াম প্রজেক্ট কার্ড
- ✅ Contact - ফর্ম এবং সোশ্যাল মিডিয়া লিংক
- ✅ Footer - ন্যাভিগেশন এবং সোশ্যাল লিংক

## 🛠️ প্রযুক্তি স্ট্যাক

- **Frontend**: React 19.1 + React Router DOM 7.6
- **Styling**: TailwindCSS 4.1 + Custom CSS
- **Animation**: Framer Motion 11.3
- **Icons**: React Icons (Feather + Simple Icons)
- **Build**: Vite 6.3
- **Deployment**: GitHub Pages

## 🚀 দ্রুত শুরু

```bash
# ইনস্টলেশন
npm install

# ডেভেলপমেন্ট সার্ভার (http://localhost:5174)
npm run dev

# বিল্ড
npm run build

# ডিপ্লয় GitHub Pages-এ
npm run deploy
```
